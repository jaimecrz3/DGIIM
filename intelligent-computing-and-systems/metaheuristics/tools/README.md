# Randomness and Timing Examples

Small C++ examples supplied alongside the metaheuristics coursework: random-number usage and factorial/timing utilities. [CMakeLists.txt](CMakeLists.txt) defines the `random` and `tiempos` executables; the latter links the system math library.

These are supporting exercises rather than a benchmark result or a standalone portfolio project. Requires a C++ toolchain and CMake; compilation was unavailable in the refactor environment. Original filenames and source credits are retained.

# Intelligent Computing and Systems

Specialization coursework in optimization, machine learning, artificial intelligence and computer vision from the Double Degree in Mathematics and Computer Science at the University of Granada.

| Area | Main contents |
|---|---|
| [Metaheuristics](metaheuristics/) | C++ subset optimization, search algorithms and saved benchmark tables |
| [Machine Learning](machine-learning/) | Sensor-data classification/regression, clustering, association rules and neural networks |
| [Computer Vision](computer-vision/) | Filtering, CNN experiments, feature matching and image stitching |
| [Intelligent Systems Techniques](intelligent-systems-techniques/) | Java heuristic-search agents, MiniZinc constraints and PDDL planning |
| [Knowledge Engineering](knowledge-engineering/) | CLIPS rules, recommendation systems and an ontology |
| [Language Processors](language-processors/) | Lex/Yacc and C implementations for language-processing assignments |
| [Human-Computer Interaction](human-computer-interaction/) | Unity planetarium interaction and museum-interface submissions |

Project READMEs explain the available evidence and execution prerequisites. Original course materials and contributor credits are retained; collaborative submissions are identified in their documentation.

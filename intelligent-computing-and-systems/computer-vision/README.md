# Computer Vision

Python coursework spanning image filtering, neural-network experiments and geometric image registration. The notebooks retain implementations, saved figures and written analysis.

| Project | Technical focus | Evidence |
|---|---|---|
| [Filtering and Multiscale Images](filtering-and-pyramids/) | Convolution, Gaussian/Laplacian pyramids, hybrid images and edge detection | Saved image experiments and discussion |
| [Deep Learning for Computer Vision](deep-learning/) | CNN configuration comparisons, ResNet34 transfer learning and Grad-CAM | Saved classification/regression evaluations and explanation examples |
| [Feature Matching and Image Stitching](feature-matching-and-stitching/) | Harris/SIFT features, descriptor matching and RANSAC homographies | Panorama examples and comparison with OpenCV Stitcher |

Tools vary by notebook: OpenCV, NumPy, scikit-image, PyTorch/fastai and TensorFlow/Keras. Project documentation identifies the required data and original environment assumptions.

**Academic context:** Computer Vision, Intelligent Computing and Systems track, Double Degree in Mathematics and Computer Science, University of Granada. Original course templates and contributor credits are retained.
